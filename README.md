# DevsFingerPrint — Control de Accesos

Agente de escritorio para Windows que registra fichadas de empleados mediante un lector biométrico DigitalPersona U.are.U. Permanece en la bandeja del sistema, conserva las fichadas localmente y las sincroniza con la API configurada.

**Tecnologías:** C# · Windows Forms · .NET Framework 4.8 · SQLite
