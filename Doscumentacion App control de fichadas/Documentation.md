## Alcance y mantenimiento

Estas guías describen el agente de este repositorio. La API y el panel web tienen repositorios y documentación propios. Los enlaces de Obsidian son relativos al nombre de la nota; los enlaces Markdown estándar también pueden usarse para referencias externas.

Actualizar la guía correspondiente cuando cambie el comportamiento observable, la persistencia, la configuración, los contratos, la instalación o las pruebas. No documentar como activa una función futura o una clave que el programa no lee.

## Estado de la documentación

La versión del ensamblado declarada actualmente es `1.0.6.0`; el script del instalador declara `1.0.7`. La discrepancia está indicada en la visión general, configuración y guía de desarrollo para que se resuelva antes de distribuir.
